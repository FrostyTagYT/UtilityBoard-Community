# 🧰 Utility Board — Community Edition

A free client-side utility board for Gorilla Tag PCVR (BepInEx). Pop it open, tweak your session, close it — all on your own screen.

## ✨ What it does
- Opens with F4 (key is configurable), plus the X button / palm gesture
- Time of day: Sunrise, Daytime, Sunset, Night, Midnight
- Weather: rain, snow, thunderstorm + intensity
- Soundboard, local music player + Spotify controls
- Session timer, local clock, performance monitor (FPS, frame time, ping, CPU/RAM)
- Optional companion app: mic mute + mic picker, OBS record/scenes/clips, TikTok LIVE stats & chat — you choose which integrations to turn on (or skip them all)

## 🔒 Fair play
- Time, weather and colors only change YOUR view — nobody else sees them
- Works in offline, private and modded rooms only. In public lobbies it hides itself and undoes its changes
- No accounts, no data collected, nothing sent anywhere

## 📦 Install
1. Install BepInEx for Gorilla Tag
2. Drop the `UtilityBoardCommunity` folder into `BepInEx\plugins`
3. Launch the game and press F4

Grab the zip from the Releases page. Full guide + troubleshooting in the README inside the zip.
